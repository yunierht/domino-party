# Amigos — servicio aislado

Solo perfiles anónimos, consentimientos y entrega de invitaciones de Dominó y Poker. No contiene motor, audio, reglas, manos ni puntuación. Cada perfil/relación/enlace tiene su Durable Object SQLite independiente. Las credenciales se guardan hasheadas; el código público no autentica. Un enlace de amistad de un uso completa la relación al aceptar el receptor y caduca en siete días. Las invitaciones de juego caducan en cinco minutos; aceptación y entrega a sala tienen confirmaciones separadas para poder reintentar.

Se usa el runtime de herramientas ya instalado en `../domino-online/node_modules`; no se modifican sus dependencias. Desde esta carpeta: `node build.mjs`, `node --test test/integration.test.mjs`, y `node ../domino-online/node_modules/typescript/bin/tsc --noEmit`. Desde raíz: `node backend/domino-online/node_modules/wrangler/bin/wrangler.js types --config backend/friends/wrangler.jsonc backend/friends/worker-configuration.d.ts`.

El binding ONLINE solo consulta el snapshot autenticado de la sala con su credencial ya existente; no crea ni modifica salas. El adaptador móvil usa el cliente y contrato actuales para crear/reutilizar/aceptar una sala. El servicio existente no se despliega ni migra por este módulo. La fecha de compatibilidad se fija al 13 de octubre por el runtime local disponible; se valida contra la misma fecha.

Rollback: conservar los tags `checkpoint/mobile-before-friends-20261018` y `checkpoint/website-before-friends-20261018`. Para restaurar comportamiento en una app ya instalada, preparar una entrega desde el checkpoint con código Android superior al publicado; no desinstalar para bajar de versión. Conservar datos del servicio de amigos aunque se retire su acceso en el cliente. No resetear otras ramas ni borrar salas o datos para deshacer la función.


Flujo actual: al presentar snapshots autenticados de los dos asientos de una sala ya conectada, se registra la amistad recíproca idempotente por juego/código/epoch. Enlaces/códigos específicos de amistad anteriores siguen opcionales. El servicio solo consulta salas por ONLINE; no las despliega ni migra. Fotos JPEG acotadas y sin metadatos se sincronizan entre amigos aceptados, sin URI locales. Presencia por refresco foreground/salida explícita y lease20s. Una invitación pendiente/aceptada no se reemplaza por doble pulsación; puede cancelarse antes de aceptar y caduca en cinco minutos. El código conserva su juego, y las credenciales de sala no se almacenan en Friends.

Quitar amigo requiere confirmación explícita en la app. El servicio elimina la relación de ambas listas y sus invitaciones pendientes, libera referencias de perfil y conserva una marca de retirada. Los snapshots repetidos de salas ya registradas no restauran la amistad; una nueva conexión explícita por enlace o consentimiento de amistad puede volver a crearla. No es un bloqueo y no cierra ninguna partida. Mismos recursos/namespace/bindings, sin migración nueva.
